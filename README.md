## v2.6.0 장비 개별 장착
집과 장비 상점의 내 장비 창에서 낚싯대·릴·찌·줄·바늘을 장착/해제합니다.
각 부위 30등급, 총 150종이며 강화는 +5까지 성공률 100%입니다.
기본 성능은 1.8^등급 × (1 + 0.1 × 강화)로, 다음 등급 +0은 이전 등급 +5의 1.2배입니다.
다음 등급 구매에는 해당 부위의 이전 등급 +5와 필요 레벨이 필요합니다. 구매 후 직접 장착하며 이전 장비는 보관됩니다.
기존 저장의 세트 등급·강화는 5부위로 이전됩니다. 총 구매·강화 예산은 기존 세트 예산을 35/22/16/17/10%로 나누며 반올림 차이만 있습니다.
낚싯대마다 타격 색상과 입자 패턴이 달라지고 강화에 따라 빛이 강해집니다.
물고기는 먼 수면에서 시작해 체력이 줄수록 가까워지며, 전설어 단계 전환에도 거리 진행이 이어집니다.
전체 350시간 여정의 실플레이 소요 시간은 이번 변경 이후 재측정하지 않았습니다.
